# 검색·장비 도감 개선

## 변경된 동작

- `/items`: 직업별 장비를 기본 화면으로 제공. 전체 아이템 탭으로 소비·주문서·기타 아이템 검색 가능.
- 직업, 무기/방어구/장신구, 상세 부위, 레벨을 조합. 구분 변경 시 이전 부위 조건 해제. 공용 장비는 직업 장비에 기본 포함하며 전용 장비만 보기로 제외 가능.
- 기본 정렬은 착용 레벨 오름차순. 같은 레벨은 ID로 순서를 고정. 목록은 36개씩 페이지 이동하며 현재 페이지 안에서 레벨별 묶음 표시.
- 장비 카드에서 기본 스탯·요구 능력치와 드롭 몬스터 최대 3종 확인. 전체 드롭처와 사냥터는 상세 링크로 연결. 드롭 미등록과 획득 불가를 구분.
- 공통 필터: 버튼 선택지, 선택지 내 검색, 레벨 구간 버튼, 직접 입력 범위 검사, 적용 조건 해제, 초기화, 접기. 선택 버튼은 즉시 적용하고 이름·직접 입력 레벨은 Enter/검색하기로 적용.
- `/mobs`, `/npcs`: 일반/보스 및 일반/상점 분류. `/maps`: 한글 맵 이름의 지역 접두어에 따른 지역 필터, 마을 구분, 페이지 이동.
- 홈 통합 검색: 검색 대상 선택 및 페이지 이동. 기존 첫 50건 제한 해소.
- 몬스터·보스·맵·NPC·퀘스트·스킬 검색의 띄어쓰기 차이를 무시하고 검색 단어를 AND 결합.
- 목록의 이전 요청이 최신 결과를 덮어쓰지 않도록 처리. 검색 제안의 시각적 순서와 키보드 순서 일치. URL 공유·뒤로가기 및 잘못된 페이지 번호 정규화.

## 검증

- `python -m unittest discover -s tests`: 65개 통과. `test_catalog_filters.py`에 직업/공용/복수 직업, 레벨·부위·페이지 조합, 숨김 데이터, 드롭 공개 범위, 띄어쓰기, 불리언 `0`, 한글 지역, DB 오류 응답 회귀 테스트 포함.
- `npm run build`: 프로덕션 빌드 성공.
- TypeScript 타입 검사와 변경한 주요 화면 ESLint 검사 통과(기존 방식의 외부 아이콘 `<img>` 경고는 유지).
- 실제 로컬 DB를 읽기 전용으로 연결한 Playwright 확인: 부위 변경, 초기화, 뒤로가기, 범위 오류, 빈 결과, 전체 아이템 전환, 맵 지역·페이지, 일반/보스·상점 구분, 모바일 390px·다크 모드. 홈 검색 대상·페이지 이동과 그룹별 자동완성 키보드 이동도 통과.

## 데이터 및 범위

- 후속 데이터 보완: [공용 장비·스킬 획득 가이드](equipment-and-skill-acquisition.md). 원작 데이터 안내를 유지하면서 확인된 현행 패치만 적용.
- 드롭 미등록 항목은 `등록된 드롭 정보 없음`으로 표시. 숨김 또는 공개 대상 밖의 몬스터는 카드의 드롭 목록에서 제외.
- 맵 지역은 현행 한글 이름에 지역 접두어가 있는 항목에 적용. 지역 정보가 없는 맵은 전체에서 조회 가능.
- 퀘스트의 기존 지역·유형 UI는 유지. 즐겨찾기/완료 숨김은 기존처럼 현재 페이지 내 표시 조건이며 전체 DB 검색 조건과는 별개.
