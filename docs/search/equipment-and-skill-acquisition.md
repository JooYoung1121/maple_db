# 공용 장비 · 크림슨우드 · 스킬 획득 가이드

2026-09-14 로컬 구현 및 데이터 대조 기록. 배포·커밋은 별도 수행하지 않았다.

## 장비와 검색

- `/items`에서 직업을 선택하면 공용 장비도 기본 포함한다. `exclusive_job=1`로 제외하며 API에는 `include_common=0`을 전달한다. API의 `include_common` 기본값도 true다.
- 범위는 **착용 레벨**이다. 카테고리·부위 조건은 그대로 적용한다. 목걸이를 함께 보려면 전체 구분 또는 장신구를 선택한다.
- 부보안관 은뱃지(1122014), 나리케인의 징표(1122059)는 기존 영문 DB 행이 있었지만 공개 목록·한글명이 누락되어 있었다. 스톰브레이커/윈드레이더/파이어브랜드/나이트섀도우 뱃지(4032006–4032009)도 같은 문제였다.
- `data/equipment_notes.json`에 검증 출처, 공개 보완 여부, 한글 이름·검색 별칭, 획득 방법을 저장한다. `api/routes/mapleland_reference.py`가 공개 범위에 합치고 `apply_mapleland_reference_names()`가 이름·별칭을 멱등 적용한다.
- 아이템 목록과 상세에 퀘스트·원정대·교환 획득 안내와 원문 출처를 제공한다. 은뱃지는 착용 Lv.50 / 퀘스트 Lv.80, 나리케인은 착용 Lv.110 / 원정대 입장 Lv.120을 구분한다.
- 교환용 뱃지 4종은 기타 아이템이다. 장비 검색에서 재료를 못 찾으면 같은 검색어로 전체 아이템에 전환할 수 있다.
- 나리케인 수치를 `mapleland_overrides.json`에 저장했다. 공격력 4, 마력 8, HP·MP 150, 명중 대신 회피 15. 기존 장비 합산 기능과 호환되도록 `inc*` 스탯 키를 유지한다. 공격/마력/HP/MP/명중→회피 변경은 공식 패치이며, 회피 수치 15 및 변경되지 않은 옵션은 기존 기본값을 유지했다.
- 통합검색·자동완성은 현행 한글명을 우선 표시한다. 별칭을 여러 개 등록해도 변형 개수가 부풀지 않는다. 중간 문자열 검색도 전체 개수·페이지 이동·동일 표시명 그룹을 유지한다.

## 옵션 편차

카오스 자쿰의 투구(1003112)에는 기존 원작 GMS 92 수집 기본값 STR/DEX/INT/LUK 21이 있었다. 메이플랜드의 실제 획득 최솟값·최댓값을 확정할 근거는 찾지 못했다. 다른 서버의 사례를 메이플랜드 값으로 사용하지 않았다.

`variation_status=unverified`와 빈 `stat_ranges`를 저장하고 화면에 **기본값 등록 · 획득 시 옵션 편차 미확인**을 표시한다. 사용자 제시 ±3을 확정된 18–24로 저장하지 않았다. 향후 확인된 범위는 출처와 함께 `verified` 및 스탯별 `min/max`로 표시할 수 있다. 강화 옵션과 기본 옵션은 구분한다.

## 스킬 획득 가이드

- `/skill-quests`, `/api/skills/acquisition` 신설. 가이드 47개: 모험가 4차 퀘스트 중심, 스킬북 7개, 상한 확장, 공통 선행, 시그너스 Lv.100 공통 조건, 배틀메이지 용사의 의지 포함.
- 직업군·세부 직업·획득 방식, 스킬/NPC/재료 검색, 공유 가능한 URL, 뒤로가기, 선행 가이드 이동, 진행 순서 펼치기, 준비물·원문 링크 제공.
- `data/skill_acquisition_guides.json`은 공략을 짧게 새로 정리한 데이터다. 블로그 원문·이미지를 재배포하지 않는다. 기분안기모띠의 빅뱅 이전 공략은 원작 자료라고 명시하고 확인된 공식 변경점을 별도로 표시한다.
- 기존 `skills`를 정확한 스킬명·직업군으로 연결한다. `mapledb_quests`의 실제 퀘스트 93개 연결(가이드 간 중복 포함)을 이용해 NPC·수집품·처치 조건을 표시한다. 아이템·몬스터 링크는 존재하고 공개된 행에만 만든다.
- `mapledb_quests.quest_id`와 기존 `/quests/{id}`의 레거시 ID 체계가 달라 해당 숫자로 잘못된 퀘스트 상세 링크를 만들지 않는다.
- 블로그의 닌자 스톰 직업 오기(나이트로드), 성스러운 기사의 검의 보상 오기(홀리/디바인 차지), 세이람 보상의 직업 구분을 바로잡았다. 리저렉션·바하뮤트 재료 수량과 바이퍼 하위 퀘스트 연결은 DB와 대조했다.
- 제네시스·홀리 차지의 변신의 비약 재료 변경(마뇽의 울음소리 1 → 용의 기운 10), 레지스탕스 용사의 의지 수정 공지를 반영했다.
- 시그너스 세부 시험·110레벨 후속 및 배틀메이지 나머지 스킬은 현행 근거가 부족하다. 공식으로 확인된 공통 조건만 안내하고 추가 확인 범위를 공개한다. 가이드 전체를 실서버 플레이로 재현 검증했다는 의미는 아니다.
